Anode

A Shopify theme built for accessory retail: it publishes the fit data customers need before they buy, and turns that data into a filter, a comparison and a bundle.

Getting started

Install Anode, then open Online Store → Themes → Customize. Everything is edited there; no code changes are required to launch a working store.

1 · Set your colours and fonts

Theme settings → Colors and Typography.

2 · Build the navigation

Header section → menu blocks. Add up to three link columns plus a featured card.

3 · Fill in product data

Create the four anode metafields so fit, comparison and bundle sections light up.

4 · Choose homepage sections

Add, remove and reorder in the left rail of the customizer.

Anode ships with one preset, also called Anode, which matches the theme's default installation state. There is no second style preset to keep in sync.

Product data model

This is the part worth setting up first. Four metafields in the anode namespace drive the fit matrix, the spec comparison, the bundle and the compatibility line on every product card. Create them once under Settings → Custom data → Products, then fill them in per product.

Namespace and keyTypeUsed by
anode.compatibilityList of single-line textFit matrix chips, product card compatibility line
anode.fit_matrixJSONFit matrix table and the fit checker
anode.fit_stepsJSONFit & install guide
anode.bundle_productsList of product referencesComplete the setup
anode.weight, .material, .standard, .ports, .warranty, .capacitySingle-line textSpec comparison rows

anode.compatibility

One line per dimension, written as Label|Value. The first two lines appear on the product card; all of them appear on the product page.

Body size|6.1–6.9"
Charging standard|Qi2 15W
Magnets|N52 neodymium
Finish|6063 anodized aluminum

anode.fit_matrix

A JSON object. values accepts yes, partial or no, so one row can express "fits with a caveat" without a second table.

{
  "axis": "Body size",
  "columns": ["6.1\"", "6.3\"", "6.7\"", "6.9\""],
  "rows": [
    { "label": "Shell Aero",  "values": ["yes", "yes", "yes", "yes"] },
    { "label": "Shell Clear", "values": ["yes", "yes", "partial", "no"] },
    { "label": "Guard Glass", "values": ["yes", "yes", "yes", "partial"] }
  ],
  "note": "Diagonal measurement of the display, rounded to 0.1 in."
}

anode.fit_steps

A JSON array of steps. image is a plain URL, so you can point at any file already in Content → Files.

[
  { "title": "Wipe the back", "text": "Dust is the only thing that stops a magnetic ring seating flat.", "image": "https://cdn.shopify.com/s/files/.../step-1.jpg" },
  { "title": "Seat the top edge first", "text": "Hook the top edge over the device, then press the bottom two corners in." }
]

Every one of these sections also works from the theme editor alone, using its own blocks. The metafields exist so you type a spec once instead of once per section.

Sections

48 sections ship with Anode. The ones below are specific to accessory retail; the rest are the standard editorial, collection and account blocks you would expect.

Homepage

  • Hero / Slideshow — split editorial hero with a slide deck, per-slide overlay controls and a magnetic call to action.
  • Popular collections — gradient cards linking into a line.
  • Compatibility & fit — on the homepage this states the four dimensions every product page publishes; on a product page it renders the live matrix.
  • Category pills — a compact index of the range.
  • Spec comparison — a table filled from metafields across a collection.
  • Complete the setup — tick-and-add bundle with a live total.
  • Press & reviews — logo strip. Ships with placeholder tiles, not real mastheads.
  • Stats, Multicolumn, Image with text, Statement, Collection list, Search, Quick links, Mini FAQ, Help banner, Newsletter.

Product page

Product details (with sticky buy column), then Compatibility & fit → Material & craft → Why Anode → Fit & install guide → Complete the setup → Spec comparison → Statement → Recommendations.

Collection page

Collection grid with facets, sort, a filter drawer on mobile, and a spec comparison table scoped to the collection being viewed.

Everything else

Cart drawer and cart page, search and predictive search, blog and article, 404, password, gift card, and the full customer account set (login, register, activate, reset, addresses, order).

Fit, compare, bundle

Compatibility & fit

Renders dimension chips, the matrix table, and an optional fit checker. The checker reads the table that is already on the page, so a customer can never be told something you did not publish.

Spec comparison

Rows are defined once as section blocks, each pointing at a metafield key. Columns are the products of a collection. Change a metafield and every comparison table updates. Tick Use the collection being viewed to reuse one block set across all collection pages.

Complete the setup

Reads anode.bundle_products, then section blocks, then a fallback collection. Selected items are added in a single request and the drawer opens. The total is summed from live variant prices — no discount figure is ever invented.

Fit & install guide

Numbered steps from anode.fit_steps or from blocks, with an optional tools line and a warranty-registration call to action.

Collection filters

Filters come from Shopify's own Search & Discovery app, so any metafield you enable there becomes filterable — including the compatibility fields above. Turn on Body size or Finish as a filter and customers can narrow a collection by fit.

If you mark a filter as swatches in Search & Discovery, Anode renders it as swatches. Colour values fall back to an initial chip when no colour or image is set, so a swatch never renders blank.

Presets

Anode ships a single preset, Anode, which mirrors the theme's default installation state. Pick it from the preset dropdown at the top of the customizer to restore the shipped configuration.

Translations

The theme ships with English, German, Spanish, French, Italian and Simplified Chinese. Storefront strings live in locales/; add or edit them under Settings → Languages so your changes survive theme updates.
