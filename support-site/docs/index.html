Getting Started

After installing the Anode theme, go to Online Store → Themes → Customize to begin editing. All theme settings are organized into sections you can toggle and configure.

Presets

Anode comes with two built-in presets:

  • Anode Clean, light-mode default preset.
  • Midnight Elegant dark-mode preset with matching dark backgrounds.

Switch between presets in the theme customizer by selecting from the preset dropdown at the top.

Sections

Hero / Slideshow

Add a hero banner or carousel to your homepage. Choose between a solid color background or upload a custom image.

Featured Products

Showcase selected products from any collection. Configure grid columns for desktop and mobile independently.

Collection List

Display all your collections in a clean, minimal grid layout.

Featured Collection

Highlight a specific collection with a curated product grid.

Color Customization

All theme colors are controlled via CSS variables in the theme settings. In the customizer, go to Theme styles to adjust:

  • Background color
  • Text color
  • Accent color (buttons, links)
  • Border and divider colors
