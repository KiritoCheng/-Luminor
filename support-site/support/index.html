Before you write

Two things make a support request much faster to resolve:

  1. The theme version — bottom right of the theme card in Online Store → Themes.
  2. The section name and, if you can, a preview link to the page where it is misbehaving.

Frequently asked

My comparison table is empty.
The section needs a collection with at least two products, and each product needs the metafield the row points at. Check Settings → Custom data → Products and confirm the keys match the row settings exactly.

The fit checker says nothing fits.
Every value in that column of anode.fit_matrix is no. The checker reads the table on the page, so the table is the source of truth — fix the JSON and the checker follows.

The bundle button does nothing.
At least one item has to be ticked. If an item's variant is sold out it is skipped when the section renders, so a bundle can end up with nothing selectable.

A colour swatch is blank.
Set a variant image, or give the variant a colour in Shopify's colour metafield. Without either, the theme shows the first letter of the variant name instead of guessing a colour.

Can I add a second style preset?
The theme ships one preset so the demo and the default install stay identical. Use theme settings and colour schemes to vary a store instead.
